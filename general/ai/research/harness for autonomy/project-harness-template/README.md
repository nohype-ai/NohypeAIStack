## How to work

- Do not commit secrets or credentials.
- Do not take an irreversible action (force-push, delete history, drop data) unless the task card says so.
- Do not widen a task past its scope and non-goals.
- Do not rewrite the task template or the task execution file in the middle of a product task.
- When a task hits real friction (repeated, costly, or sure to hit the next run), file a harness task on [the board](tasks/BOARD.md) instead of only working around it in chat. Product work still finishes first.
